04 / Thử thách văn chương

Đọc sâu hơn.
Chơi cùng con chữ.

Thử sức với câu hỏi trắc nghiệm ngắn. Đây là mô-đun mẫu có thể phát triển thành trò chơi sắp xếp sự kiện, ghép nhân vật và hoàn thành câu chuyện.

Cách mở file này để nghe được trên điện thoại Android (Chrome):
  1. Mở ứng dụng Tệp (Files / My Files) → thư mục Tải xuống.
  2. Chạm vào file Dau_An_Van_Chuong.html → chọn Chrome → Chỉ một lần.
  3. Nếu mở từ Zalo/Messenger: bấm nút ⋮ → Mở bằng trình duyệt (hoặc lưu file về máy rồi làm như trên).
iPhone / iPad:
  1. Safari không mở thẳng file HTML trong máy. Hãy cài ứng dụng miễn phí Documents by Readdle.
  2. Lưu file vào Documents (Chia sẻ → Documents), rồi chạm vào file để mở bằng trình duyệt trong ứng dụng.
  3. Cách ổn định nhất: đưa file lên một trang web (ví dụ Netlify, GitHub Pages) rồi mở đường link bằng Safari.

Mẹo: nhớ tắt chế độ im lặng (gạt công tắc bên hông iPhone) và tăng âm lượng media.

Điều gì còn ở lại
sau khi bạn đọc?
